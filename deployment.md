# Deployment

## 1. Run locally

Prerequisites: Podman or Docker (with a compose provider), [uv](https://docs.astral.sh/uv/), Node 20+.

1. Start Postgres:
   ```
   docker compose up -d          # or: podman compose up -d
   ```
   Without a compose provider:
   ```
   podman run -d --name kisht-db -e POSTGRES_USER=kisht -e POSTGRES_PASSWORD=kisht -e POSTGRES_DB=kisht \
     -p 5432:5432 docker.io/library/postgres:16
   ```
2. Create the test database (used by pytest):
   ```
   podman exec kisht-db psql -U kisht -c "create database kisht_test"
   # with compose: docker compose exec db psql -U kisht -c "create database kisht_test"
   ```
3. Backend environment. Create `backend/.env` (git ignores it):
   ```
   DATABASE_URL=postgresql+asyncpg://kisht:kisht@localhost:5432/kisht
   JWT_SECRET=<32 or more random characters>
   SEED_PASSWORD=<password for the demo accounts>
   CORS_ORIGIN=http://localhost:3000
   COOKIE_SECURE=false
   ```
   To make a secret: `python3 -c "import secrets; print(secrets.token_hex(32))"`.
4. Install, migrate, seed and start the backend:
   ```
   cd backend
   uv python install 3.13
   uv sync
   uv run alembic upgrade head
   uv run python -m app.seed      # wipes and reloads all tables
   uv run uvicorn app.main:app --port 8000
   ```
5. Frontend, in a second terminal. `BACKEND_URL` defaults to `http://localhost:8000`; to change it, put `BACKEND_URL=...` in `frontend/.env.local`.
   ```
   cd frontend
   npm install
   npm run dev
   ```
   Officer app: http://localhost:3000. Manager: http://localhost:3000/manager/login.
6. Tests:
   ```
   cd backend && uv run pytest
   cd frontend && npx eslint app lib components && npx tsc --noEmit
   ```
   pytest reads `TEST_DATABASE_URL` if set, otherwise uses `kisht_test` on localhost.

## 2. How it is deployed

**API on Render.** It is defined in `render.yaml` and created as a Blueprint:
- Docker runtime, root directory `backend`, region Singapore, free plan, auto-deploy from `main`.
- The container runs `alembic upgrade head` on every start, then uvicorn.
- Health check: `/health` (checks the database).
- `JWT_SECRET` is generated by Render and `COOKIE_SECURE` is `true`. `DATABASE_URL`, `CORS_ORIGIN` and `SEED_PASSWORD` are entered in the dashboard.

**Frontend on Vercel.**
- Root directory `frontend`, function region `sin1`; both are set in the Vercel project settings.
- `BACKEND_URL` points at the Render URL. It is read at build time, so redeploy after changing it.
- `next.config.ts` rewrites `/api/*` to the backend. The browser only talks to the Vercel domain, so the session cookie is first-party.

**Database on Neon** (Postgres, Singapore region). asyncpg needs this URL format:
```
postgresql+asyncpg://USER:PASSWORD@ep-xxxx.c-3.ap-southeast-1.aws.neon.tech/DBNAME?ssl=require
```
Neon's dashboard gives `postgresql://...?sslmode=require&channel_binding=require`. Change the scheme to `postgresql+asyncpg://` and replace the query with `?ssl=require`. asyncpg rejects `sslmode` and `channel_binding`. Use the direct host, not `-pooler`.

**Seed the live database from a laptop** (once; the seed wipes all tables):
```
cd backend
export DATABASE_URL='postgresql+asyncpg://...?ssl=require'
export JWT_SECRET=$(python3 -c "import secrets; print(secrets.token_hex(32))")
export SEED_PASSWORD='<DEMO_PASSWORD>'
uv run alembic upgrade head && uv run python -m app.seed
unset DATABASE_URL JWT_SECRET SEED_PASSWORD
```
If the Neon host does not resolve (`Name or service not known`), the local router's DNS may be refusing it. Point the network interface at a public resolver, e.g. `sudo resolvectl dns <interface> 1.1.1.1 8.8.8.8`.

## 3. Environment variables

| Name | Where | Purpose |
|---|---|---|
| `DATABASE_URL` | backend | Postgres connection, `postgresql+asyncpg://...` |
| `JWT_SECRET` | backend | Signs session tokens; 32+ characters, required |
| `CORS_ORIGIN` | backend | Allowed browser origin (the frontend URL) |
| `COOKIE_SECURE` | backend | `true` in production; `false` only for local http |
| `SEED_PASSWORD` | seed script | Password given to all demo accounts |
| `TEST_DATABASE_URL` | tests | Optional; database pytest uses |
| `BACKEND_URL` | frontend | API base the `/api` rewrite points to (build time) |

## 5. Notes

- Render's free tier sleeps when idle. The first request after a pause can take up to about 50 seconds.
- Sample CSVs are in `sample-data/` and can be downloaded from the manager import screen: `overdue-sample.csv` (clean) and `overdue-with-errors.csv` (the same rows plus 5 bad ones, to show the error report).
